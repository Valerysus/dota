# Dota 2 AI Coach & Match Analyzer (OpenDota Live API)

[![Live Demo](https://img.shields.io/badge/Live%20Demo-GitHub%20Pages-brightgreen)](https://valerysus.github.io/dota/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Повнофункціональний односторінковий веб-додаток (**Single-File HTML/CSS/JS**) для тренерського розбору матчів Dota 2 на базі публічного **OpenDota Live API**.

Працює виключно в браузері напряму без бекенду, без встановлення залежностей та без обов'язкового API-ключа завдяки відкритим CORS-запитам.

🌐 **Онлайн демо:** [https://valerysus.github.io/dota/](https://valerysus.github.io/dota/)

---

## Швидкий старт

1. Відкрийте онлайн-версію на [GitHub Pages](https://valerysus.github.io/dota/) або завантажте локально `index.html`.
2. Відкрийте `index.html` у будь-якому сучасному веб-браузері (Chrome, Edge, Firefox, Brave, Safari).
3. Додаток автоматично завантажує демо-матч (`9044569588`) або дозволяє ввести будь-який Match ID чи профіль гравця.

---

## Розумний ввід (Smart Search)

Універсальне пошукове поле автоматично визначає тип введених даних з підтримкою fallback-проби:
* **Match ID** (наприклад, 10-значний `9044569588` або старіші матчі від 5 цифр) — завантажує повну телеметрію матчу та розгортає детальний розбір для всіх 10 гравців.
* **Steam32 Account ID** (наприклад, `94054712`) — завантажує профіль гравця, ранг, вінрейт за останні 20 матчів та історію поєдинків.
* **17-значний SteamID64** (наприклад, `76561198054320440`) — автоматично конвертується у Steam32 за формулою `BigInt(input) - BigInt("76561197960265728")`.
* **Прямі посилання** на матч або профіль з OpenDota, Dotabuff чи Stratz розпізнаються автоматично.
* **Fallback-проба**: якщо 10-значний ID не знайдено як матч, система автоматично спробує перевірити його як профіль гравця (і навпаки).

## Ключові модулі аналітики

### 01. Оцінка драфту та математика протипіків (Draft Advantage)
* Розрахунок командного шансу на перемогу за драфтом на базі матриці 5 стовпів композиції (контроль, пуш, тімфайт, лейтгейм, темп).
* **Автентична оцінка впливу для кожного героя**: відображає реальний внесок (`+2.4%`, `-1.8%`, `+3.2%`), що не обнуляється при збалансованому підсумку.
* **Безпечні рекомендації контрпіків (`safeSuggest`)**: алгоритм аналізує композицію обох команд і пропонує альтернативи, **виключаючи самого героя та вже зайнятих персонажів матчу**.
* Спеціальні профілі для ключових персонажів (Juggernaut, Ursa, Queen of Pain, Nyx Assassin, Winter Wyvern, Lina, Slark, Lion тощо).

### 02. Інтерактивні графіки переваги та ймовірності перемоги
* **Графік золотої переваги (Gold Adv)**: динаміка від 0:00 до падіння Трону з плавною заливкою (Radiant / Dire).
* **Графік досвіду (XP Adv)**.
* **Орієнтовний шанс на перемогу (Win Probability %)**: динамічна логістична евристика, що враховує масштаб переваги за ресурсами у часі гри.
* **Графік нетворсу всіх 10 гравців**: плавні криві з підписами героїв на кінцях ліній, тултіпом та інтерактивною легендою для фокусування на окремому гравцеві.

### 03. Підсумок матчу (Post-Mortem) та Stratz-style IMP Score
* **Динамічні фактори результату**: жодних статичних шаблонів. Фактори перемоги та поразки генеруються на основі:
  * переваги на стадії лайнінгу на 10:00 (`adv10`);
  * переломного 3-хвилинного вікна з найбільшим свінгом золота;
  * урону по будівлях (`tower_damage`) та різниці знесених веж;
  * контролю огляду (кількість Observer та Sentry вардів);
  * розриву в нетворсі між ключовими керрі та відловлювань гравців із найбільшою кількістю смертей.
* **Індивідуальний рейтинг впливу (IMP Score від -50 до +50)**: аналог Stratz IMP для кожного з 10 гравців на основі внеску в бійки, урон, пуш веж та вардинг з бейджами **MVP** та **SVP**.

### 04. Аудит дисципліни матчу та спортивної чесності (Fair Play Audit)
* **Об'єктивний аналіз телеметрії**:
  * Офіційний статус технічного виходу з гри від Valve (`leaver_status` — Abandoned, AFK Abandon, Disconnected);
  * Атипова результативність на мікро-інтенсивних героях (Arc Warden, Tinker, Meepo);
  * Нові акаунти Steam32 (діапазон 2024–2026 рр.) із високою часткою урону (ознака смурфінгу);
  * Аномальна частота смертей (Feeding) та критичний недофарм;
  * Екстремальний темп дій (APM $\ge 480$).
* **Дисклеймер та перевірка у Steam**: прямі кнопки перевірки профілю у Steam для перевірки офіційного статусу блокувань (Game Ban / VAC Ban від патруля Overwatch та античиту Valve).

### 05. Бенчмарки проти медіани героя (OpenDota)
* Пряме підвантаження еталонних медіан через `/benchmarks?hero_id`.
* Порівняння GPM, XPM, LH/хв, LH@10, урону по героях та будівлях із наочним відображенням різниці (`+112 (+24.5%)`).

### 06. Фаза лейнінгу (0:00 – 10:00) та контр-білд
* Крипстат на 10-й хвилині (LH@10) проти стандарту ролі.
* Витрати золота на відновлювальні розхідники до 8-ї хвилини.
* Таймінги покупок ключових артефактів (BKB, Blink Dagger, Manta, Orchid тощо) з оцінкою відхилення від орієнтовних таймінгів.

### 07. Плаваючий док героїв (Floating Hero Dock)
* Закріплена панель із портретами 10 героїв для швидкого перемикання між гравцями без зайвого скролу.

## Надійність та оптимізація OpenDota API

1. **Кешування у localStorage на 24 години**: великі статичні довідники героїв (`/heroStats`) та предметів (`/constants/items`) кешуються із перевіркою терміну життя (TTL 24 год), знижуючи кількість мережевих викликів.
2. **Підтримка API-ключа**: необов'язковий ключ можна зберегти безпосередньо в інтерфейсі сайту або в `localStorage` під назвою `opendota_api_key`.  
   *Примітка щодо безпеки: Ключ зберігається у вашому браузері (localStorage) відкритим текстом. Не вводьте його на чужих комп'ютерах.*
3. **Експоненційне очікування при 429**: автоматична пауза та повторна спроба при досягненні ліміту частоти запитів.
4. **Захист від спаму повторних запитів парсингу**: 2-хвилинний cooldown на надсилання POST `/request/{match_id}`.

## Розгортання та збірка

Файл `index.html` генерується через Python з автоматичною перевіркою валідності JS-синтаксису (`node --check`):
```bash
python build_site.py
```
Вихідний файл `index.html` не має зовнішніх залежностей (окрім публічного API) і готовий для деплою на GitHub Pages, Cloudflare Pages або локального використання.
